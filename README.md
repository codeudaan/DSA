# DSA in C — Beginner to Advanced

A personal learning repository for mastering **Data Structures and Algorithms (DSA) using C**, starting from the absolute basics and gradually progressing toward problem-solving and placement-level DSA.

This repository is built for learning by **writing, testing, breaking, debugging, and understanding code** rather than simply memorizing solutions.

---

## 🎯 Goal

The goal of this repository is to build a strong foundation in:

- C programming required for DSA
- Data Structures
- Algorithms
- Problem-solving
- Time & Space Complexity
- Competitive programming fundamentals
- Placement/interview-oriented DSA

## 🧠 Learning Approach

Each topic is approached using:

```text
Concept
   ↓
Understand the logic
   ↓
Write C code
   ↓
Dry Run
   ↓
Test
   ↓
Debug
   ↓
Analyze Complexity
   ↓
Solve Problems
```

The focus is on **understanding the algorithm**, not memorizing code.

```bash
./program
```

### Windows

```bash
program.exe
```
